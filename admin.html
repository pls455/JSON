إدارة المحتوى

الواجهة مجهزة لتصبح CRUD حقيقية عبر Firestore. لن يتم حفظ أي بيانات حتى نضع إعداد Firebase وقواعد الأمان.

هيكل Firestore المقترح

نبني البيانات بهذا الشكل حتى يبقى المشروع قابلًا للتوسع.

branches{ name, description, order, active }
subjects{ name, branchId, description, order, active }
lessons{ title, subjectId, description, order, active }
quizzes{ title, lessonId, duration, active }
questions{ quizId, text, options[], correctIndex, explanation }
admins{ uid, email, role, active }

الخطوة التالية

أضف إعدادات Firebase في firebase-config.js ثم نربط Authentication وFirestore ونحوّل الأزرار المعطلة إلى لوحة تحكم كاملة.
